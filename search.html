Prefix syntax

You can use prefixes directly in the search bar for precise queries. Prefixes can be combined in a single search.

@gradient01 — search by creator name

#game — search by tag (exact match)

%maze_generator — search by script name

$fun — search in descriptions only

@gradient01 #game — combine multiple prefixes
