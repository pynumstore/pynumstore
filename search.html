Prefix syntax

The search system supports special prefixes to target specific fields. Quotes can be used to force an exact match.

Syntax Search in Behavior
word All fields Fuzzy search in name, creator and description
"word" All fields Exact search
@word Creator Search only in creators
@"word" Creator Exact creator match
#word Tags Search only in tags
#"word" Tags Exact tag match
%word Name Search only in script names
%"word" Name Exact script name match
$word Description Search only in descriptions
$"word" Description Exact description match

Special wildcard

The wildcard * can be used to display all scripts without applying a text filter. This is useful when combined with sorting or advanced filters.

*

Displays all scripts.

*

Combined with Newest update, this allows browsing recently updated scripts.

Examples

@"John"

Finds scripts created by the exact creator John.

%"My Script"

Finds the script with the exact name My Script.

#python

Finds scripts containing the python tag.

$"web scraper"

Finds scripts with the exact description phrase.
