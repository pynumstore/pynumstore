Search syntax

Use prefixes to target specific fields. Add quotes around any term to force an exact match. Prefixes can be combined in a single query.

@
Creator
@gradient01 fuzzy
@"gradient01" exact
#
Tags
#game fuzzy
#"game" exact
%
Script name
%maze fuzzy
%"maze_gen" exact
$
Description
$physics fuzzy
$"physics" exact word
*
Wildcard

Displays all scripts. Combine with sorting or advanced filters for powerful browsing.
